How to write one

Use <p> for paragraphs, <h2> for headings and <ul><li> for lists. You don't need <html> or <body> tags.

  • Put the file in the articles folder, for example my-first-review.html.
  • Add one entry for it in articles.json with the same name (without .html) as its slug.
  • Remove "sample": true from your real articles.
Tip: use this space for things that don't fit in a reel, like full review details, setup guides and AI notes.
